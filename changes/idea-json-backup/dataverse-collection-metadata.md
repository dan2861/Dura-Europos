# Proposed Dataverse collection metadata

Prepared 2026-11-09 for Danu to enter in Yale Dataverse's New Dataverse form. This proposal describes the collection that will contain datasets; production-dataset-metadata.md describes the individual November 2026 export dataset. No collection has been created or its identifier availability checked by the assistant.

| Field | Proposed value |
|---|---|
| Dataverse Name | IDEA — Wikidata Research Data |
| Identifier / URL alias | idea-wikidata, if available |
| Category | Research Project, if offered |
| Affiliation | The project's actual institutional affiliation; leave blank if optional and not yet settled |
| Email | The monitored project/contact email Danu chooses |
| Dataset Metadata Language | English, if offered |
| Metadata Fields | Retain the host collection's defaults, including Citation metadata |
| Browse/Search Facets | Retain inherited defaults initially; Subject, Keyword and Author Name are useful if offered |

## Description to paste

Research datasets documenting Wikidata items associated with the IDEA project. This collection is intended for preserved JSON exports and accompanying documentation, selection records, provenance and verification evidence. These materials support reproducible research and the maintenance of links between Wikidata and institutional collection records.

## Scope and next step

The collection description deliberately has no fixed item count or export date; those belong in each dataset's metadata. This does not promise recurring backups or claim files have already been deposited. No expansion of IDEA, institutional endorsement, affiliation or email is inferred.

Choose the appropriate parent/Host Dataverse where Danu has creation rights. After creating the collection, use its own Add Data → New Dataset action and apply [production-dataset-metadata.md](production-dataset-metadata.md). Keep the existing pilot dataset separate; creating the collection does not move it or upload the production files. Return the new collection URL so the destination can be recorded. Publication remains a later separate step.
